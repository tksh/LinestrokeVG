LinestrokeVG (.lsvg)

LinestrokeVG (short for Linestroke Vector Graphics) is a vector graphics format optimized for stroke-based illustrations. It uses a streamable data structure that can be recorded in real time as strokes are drawn, and defines a shared model for layers and attributes across all stroke types.

Stroke Types

  • Straightlines (stln): Constant-width straight line segments
  • Wavestrokes (wvst): Variable-width vector brush strokes
